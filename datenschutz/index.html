Hosting über GitHub Pages

Diese statische Website wird über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technisch erforderliche Nutzungsdaten, insbesondere IP-Adresse, Geräte-/Browserinformationen, Datum und Uhrzeit, aufgerufene Seiten und Referrer. GitHub weist ausdrücklich darauf hin, dass IP-Adressen von Besuchern einer Pages-Site aus Sicherheitsgründen protokolliert und gespeichert werden.

Die Bereitstellung und Absicherung der Website liegt in meinem berechtigten Interesse gemäß Art. 6 Abs. 1 lit. f DSGVO. Empfänger ist GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA; für Europa nennt GitHub außerdem GitHub B.V., Prins Bernhardplein 200, 1097JB Amsterdam, Niederlande.

GitHub verarbeitet Daten auch in den USA und anderen Ländern. Nach der GitHub Privacy Statement stützt GitHub internationale Übermittlungen insbesondere auf das EU-US Data Privacy Framework und Standardvertragsklauseln. Speicherdauer und weitere Verarbeitung verantwortet GitHub nach seiner Erklärung.

Keine eigene Reichweitenmessung

Ich setze auf dieser Website keine eigene Analyse, Werbung, Profilbildung, Social-Media-Pixel, externen Schriftarten oder eingebetteten Videos ein. Die Website speichert selbst keine Cookies und keinen Local Storage. Die Registerkarten verwenden nur den URL-Hash im Browser. Technisch notwendige Verarbeitungen durch GitHub richten sich nach GitHubs eigener Erklärung.

Der Veröffentlichungsstatus der Apps wird serverseitig durch einen zeitgesteuerten GitHub-Workflow mit dem öffentlichen Apple-Katalog abgeglichen und als statische Datei veröffentlicht. Beim bloßen Besuch dieser Website wird deshalb keine Anfrage vom Endgerät an Apple ausgelöst. In der Statusdatei stehen ausschließlich öffentliche App-Metadaten, Bundle-IDs und Prüfzeitpunkte, keine Besucherdaten.
